Implementation Notes
GR Basic Details

Status should be "booked" when creating new bilty

Vendor Selection

Vendor list should load and address should populate automatically

Party / Customer Details

When vendor is selected, load details in Consignor fields with address

Bill To / Ship To Party

Should be fetched from consignor and consignee respectively

Vehicle / Transport Details

When selecting vehicle, load respective details in Vehicle fields

Driver Details

Should be loaded from driver table and update in bilty

Freight / Charge Heads

Add dropdown to select from ratelists, fields should update automatically

Payment / Collection Details

Payment Status should be marked automatically based on payment received and Freight due

Remove Proof / Delivery Confirmation

Remove from Bilty creation form

New Tab - Proof / Delivery Confirmation

Select from bilty list, upload proof with: Delivered By, Received By Name, POD Number, Seal Number, Damage/Shortage Report, Closed By, attachment space. Mark delivery as completed.

Payment Receipts

Add Bilty dropdown, load Balance amount automatically. User enters amount received. If short, difference marked as TDS (editable). If still pending, optional amount field with reason. Multiple receipts allowed until balance is zero.

Payment Calculation

Net freight + GST = Freight Due. Freight Due - Advance = Balance. Advance = Paid Amount. Paid = Freight Due = Paid Amount. Unpaid = Freight Due > Paid Amount.
